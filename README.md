# Zoe Harvest Ministries — Coming Soon

A responsive, animated, static coming-soon website for GitHub Pages.

## Add your image files

Place your real image files in `assets/images/` with these exact filenames:

- `zhmlogo.png` — ministry logo
- `apostlejm.png` — Apostle's portrait

The page is configured to use these paths. If you prefer to keep both image files in the repository root, update the image paths in `index.html`.

## Publish to GitHub Pages

1. Create a repository named `site` under the GitHub username `zoeharvestministries`.
2. Upload the contents of this folder to the repository root (the `index.html` file should be at the root).
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/(root)`, then save.
5. After deployment, visit `https://zoeharvestministries.github.io/site/`.

## Before launch

- Confirm that the logo and Apostle portrait appear correctly.
- Verify the location and service details.
- Confirm that the Facebook page is still the ministry's official page.
- Add official YouTube, TikTok and WhatsApp Channel links when available.
- Add actual book titles and downloads when the resources are ready.

This is a static site and can later be moved to regular hosting or connected to a custom domain.
